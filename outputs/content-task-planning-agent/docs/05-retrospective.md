# 复盘

## 最难的问题

最难的是证明 Agent 不是串行调用器。解决方案是让 premium 的真实估算结果触发 lean 重生成与重估算；工具失败也会改变方案，同时保留先前成功步骤。

另一个难点是避免模型篡改成本或直接声称成功。控制器只采用工具产生的最新估算，保存工具再次校验约束，最终状态以持久化 observation 为准。

## 学习收获

- 重规划必须产生新的工具结果，而不是只修改输出文本。
- 步骤状态应追加记录，失败历史不能被后续成功覆盖。
- 提示词负责决策，控制器负责不可突破的业务边界。

## 下一步

1. 将失败步骤和中间结果持久化，实现跨进程 checkpoint/resume。
2. 接入真实日历、素材库和报价服务。
3. 增加真实模型动作正确率、成本和延迟评测。
4. 使用数据库事务和唯一键支持并发。

## 实际用时与未完成项

实现、自查、测试和文档约 1.5 小时（AI 辅助）。未实现跨进程断点续跑、生产数据库、真实业务工具和 UI；同一执行内的失败步骤续跑已实现。
