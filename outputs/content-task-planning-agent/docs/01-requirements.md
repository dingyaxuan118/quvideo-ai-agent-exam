# 需求与成功标准

## 用户与目标

内容运营人员需要在给定主题、预算和截止时间内形成可保存的内容活动方案，并能清楚看到业务任务计划、独立的执行步骤状态、工具结果、最终脚本与素材、成本合计和未完成原因。

## 输入与范围

输入：主题、预算、剩余截止小时数。合成资料包含 premium 与 lean 两套素材、费用及耗时。工具包括素材检索、脚本生成、成本估算和方案保存。

范围外：UI、真实素材平台、投放执行、多人审批和生产级数据库。

## 成功标准

1. 正常约束下保存完整方案。
2. 缺少预算或截止时间时明确返回不完整。
3. 工具失败时调整计划，保留成功步骤，并可继续执行失败步骤之后的链路。
4. 初始方案超预算或超时后改选替代方案并重新估算。
5. 没有可行方案时返回未完成及实际缺口，不把失败步骤标成功。
6. 重复执行只保留一份方案。
7. 达到步数上限时安全停止。
