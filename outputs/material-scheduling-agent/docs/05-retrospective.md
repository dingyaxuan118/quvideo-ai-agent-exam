# 复盘

## 最难的问题

最难的是同时处理“模型需要动态决策”和“不能擅自改变硬性发布时间”。解决方式是把冲突结果反馈给模型，但默认只允许输出替代建议；只有请求显式携带确认时间后才保存该草稿。

第二个难点是避免保存失败或重复请求造成误报。保存工具返回 `saved`、`duplicate` 和 `draft_id`，最终状态完全基于真实 observation，而非预期流程。

## 学习收获

- Agent 的价值不仅是调用多个工具，更在于观察失败或冲突后改变动作。
- 能力白名单比提示词更可靠：没有发布工具，就能显著降低越权风险。
- Trace 应记录可验证的输入输出和简短决策依据，而不是模型内部思维过程。
- 离线 Mock 对流程回归很有用，但不能替代真实模型评估。
