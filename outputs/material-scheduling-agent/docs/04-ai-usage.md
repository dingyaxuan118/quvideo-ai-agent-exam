# AI 辅助使用记录

## 使用范围

使用 AI 辅助梳理题目验收点、设计项目结构、生成第一版代码、测试和文档。

## 个人贡献与修改

- 将题目中的“审核、冲突、确认、保存”要求转化为明确状态机和输出字段。
- 确定不提供发布工具，从能力层面限制越权发布。
- 设计冲突时默认等待确认、幂等 request key、保存失败故障注入和最大步数保护。
- 审查 AI 生成代码，补充异常路径、自动化测试和离线运行入口。

## 验证方式

通过 `unittest` 覆盖六个必须验收点和步数上限，并实际运行 CLI 生成 `examples/` 中的输入、输出和 Trace。没有把 AI 输出直接视为正确结果；以测试断言和实际工具返回为准。

## 边界说明

提交材料不包含 API Key、个人数据或真实业务素材。离线策略模型明确标注为 Mock，不用于声称真实模型决策效果。
