# 需求与成功标准

## 用户与目标

内容运营需要从待处理素材中识别信息缺失与规则风险，在已有排期约束下形成可确认的发布排期草稿。系统不接真实发布接口。

## 范围

输入为素材 ID、期望发布时间及可选的替代时间确认。合成数据提供素材元数据、审核规则和已有排期。系统提供素材读取、规则检查、时段查询、草稿保存四个工具。

输出包括审核状态、风险原因、建议时段、待确认项、草稿保存状态、任务状态和可审计 Trace。

不在范围内：UI、线上部署、账号权限、真实素材库、真实发布和生产级并发控制。

## 成功标准

1. 正常素材可形成且仅形成草稿。
2. 信息缺失时列明缺失项，不进入排期保存。
3. 命中规则时明确阻断并给出原因。
4. 时段冲突时建议替代时段，未经确认不擅自改变硬性要求。
5. 同一请求重复保存只有一条草稿。
6. 保存失败如实返回失败，不虚报成功。
7. 每次执行具有步数上限和可读 Trace。
