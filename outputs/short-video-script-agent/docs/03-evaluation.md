自动化测试覆盖 31 项，实际结果记录在 `examples/test-results.txt`。

重点验证：30 秒请求首稿超过 30 秒后被压缩并重新估算；每个分镜同时计算旁白与字幕阅读时间；最终输出时长等于 Trace 中最终脚本指纹的结果；更改脚本不能复用旧规则检查；80%、4K 及同句夹带的 8K 等素材外陈述失败；无关但已检索的素材不能用于当前主题；新增品牌禁用词立即生效；替换 P01 事实后脚本同步变化；缺输入、无素材、工具失败和步数耗尽返回准确状态。

示例文件覆盖正常超时修正、资料不足、工具失败及无法满足极短时长。真实 OpenAI 模型未在无密钥环境调用，因此只声明入口和 Schema 可用，不以离线 Mock 冒充真实模型效果。
