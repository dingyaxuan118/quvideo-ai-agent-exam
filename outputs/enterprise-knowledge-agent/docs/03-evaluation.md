## 评价指标

- 引用支持率：测试中所有成功答案引用均来自真实 excerpt。
- 冲突安全率：冲突案例不输出单一期限。
- 状态准确性：失败、资料外和步数耗尽分别使用不同状态。
- 知识可替换性：删除 D02 并把 D01 改为 45 天后，答案随数据变为 45 天。

真实模型入口未在无 API Key 环境调用，因此不把离线 Mock 的通过率包装成模型质量结论。
