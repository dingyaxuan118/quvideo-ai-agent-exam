# 04 AI 使用说明

本项目开发过程中使用 AI 辅助拆解题面、设计 ReAct 状态机、生成初稿与测试案例，并由开发者通过本地执行结果校验和修正。

运行时提供两种决策实现：

- `OpenAIDecisionModel`：真实模型入口。使用 OpenAI Responses API 和结构化输出，每一步接收当前问题、历史与全部工具观察，再选择下一个动作。
- `OfflinePolicyModel`：无网络、无密钥时的确定性 Mock，只用于复现编排、工具和安全护栏；不能证明大模型的语义泛化质量。

密钥只能通过 `OPENAI_API_KEY` 环境变量注入，`.env.example` 只含占位符。系统提示要求模型不得伪造引用或自行裁决冲突，控制器还会独立复核，避免仅依赖提示词。
