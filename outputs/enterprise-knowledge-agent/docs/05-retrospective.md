# 05 复盘

## 做得较好

检索与原文读取分离，使引用证据链清晰；最终答案不信任模型自行提供的 quote，而是对照工具观察验证。冲突规则放在控制器，能防止模型因“新文档优先”的直觉擅自选择 15 天。故障注入让恢复路径可重复测试。

## 开发中发现的问题

初版词法检索中，“多久”这一通用词会让年假问题弱命中报销制度，进而产生伪冲突。修复方式是要求至少两个相关特征命中，并为口语改写显式加入别名 token。第二次测试又发现“几天”别名只作为长字符串加入、没有生成二元词组，随后修正并由回归测试锁定。

## 后续改进

生产版应接入权限过滤、向量与关键词混合检索、文档有效期/制度层级、引用定位到页码和段落、人工确认闭环、可观测性与真实模型评测集。冲突判断还应从当前的 `topic + 正文不同` 升级为结构化事实抽取，避免把互补信息误判为冲突。
